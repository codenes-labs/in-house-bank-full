# Escrever spec

1. Ler `docs/principios.md`, `docs/banco.md` e as specs vizinhas.
2. Criar `docs/specs/SPEC-NN-nome.md` com objetivo, regras, critérios de aceite e testes.
3. Não inventar regra que não esteja no pedido ou nas regras já documentadas.
4. Dúvida: perguntar. Não escrever código de produção nesta skill.
