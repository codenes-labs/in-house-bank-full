# Planejar sprint

1. Ler `docs/sprints` e as specs citadas.
2. Quebrar em tarefas de checklist, sem inventar entrega extra.
3. Respeitar o que já está feito.
4. Uma sprint não começa a implementação antes da spec correspondente.
