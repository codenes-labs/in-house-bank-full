# In House Bank

Controle pessoal de empréstimos e compras parceladas. O app não movimenta dinheiro.

```bash
npm install
npm test
npm run dev
```

Para a conta na nuvem, copie `.env.example` para `.env` com a URL e a chave anônima do Supabase. O login com Google depende do provider ligado no painel. A migration está em `supabase/migrations`.
